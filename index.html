Modernización de Bus de Servicios con Sistema de Mapeo Dinámico

.NET 10 · Microservicios · REST / SOAP · CI/CD · SDD · Harness Engineering

  • Ejecuté como único desarrollador la modernización de un bus de servicios con más de 130 endpoints, migrando 50 endpoints a 3 microservicios en .NET 10, agrupados por dominio funcional.
  • Diseñé e implementé un cuarto microservicio de mapeo dinámico que permite a clientes personalizar contratos de request/response de forma segura, eliminando la duplicación de endpoints que existía por requerimientos específicos de cada proveedor.
  • Arquitectura modular con artefactos compartidos: capa de persistencia común (misma base de datos), adaptador HTTP unificado (REST y SOAP), artefacto de dominio compartido y abstracción reutilizable de capa de presentación.
  • Apliqué metodología SDD (Specification-Driven Development) con Harness Engineering, usando modelos de IA (Sonnet, Gemini, Kimi) según el tipo de tarea, gestionados con OpenCode y GitHub Copilot.
  • Implementé un agente de QA especializado en el harness para levantar documentación de pruebas enfocada en la definición de especificaciones.
  • Documenté el proyecto con pruebas unitarias y de integración, y desplegué la solución completamente funcional en ambiente de desarrollo.
  • Configuré pipelines de CI/CD para integración y despliegue continuo.
