# Landing Page — Currículum Profesional

Página web estática de currículum profesional, desarrollada con HTML, CSS y JavaScript puro. Diseño sobrio orientado a entornos empresariales con animaciones de desplazamiento reveladoras.

## Características

- **Diseño responsive** adaptable a dispositivos móviles y escritorio
- **Animaciones de descubrimiento** al hacer scroll (reveal up, left, right)
- **Timeline interactiva** con indicadores de experiencia que se iluminan al navegar
- **Modal personal** con flip card que alterna entre perfil profesional y personal
- **Edad dinámica** calculada automáticamente desde la fecha de nacimiento
- **Chips de contacto** con enlaces directos a WhatsApp y LinkedIn
- **Paleta corporativa** basada en azul marino profesional

## Tecnologías

- HTML5 semántico
- CSS3 con custom properties, grid, animaciones y transiciones
- JavaScript para interacciones, observers y lógica dinámica
- Sin dependencias externas, frameworks ni librerías

## Estructura del proyecto

```
cv/
├── index.html     # Estructura y contenido
├── style.css      # Estilos y animaciones
├── script.js      # Lógica de interacción
├── Foto.jpg       # Foto profesional
└── foto_1.jpg     # Foto personal (cara trasera del modal)
```

## Uso

Abrir `index.html` en cualquier navegador. No requiere servidor, compilación ni instalación.
